### Data Abstraction
- a way to *hide complex details* and show only what's necessary.
---
#### 3-Level Abstraction of Database
1. **View Level** 
	- is the highest level
	- is accessible to all users
	- is the simplest most basic level

2. **Logical/Conceptual Level**
	- describes what data is kept in the database and how those data are connected to one another
	- attempts to describe the full or complete data set by defining what tables should be built and what the relationships between those tables should be

3. **Physical Level**
	- defines how data is stored, data structures for storing data, and database access procedures.
